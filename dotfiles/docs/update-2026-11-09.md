# November 9 window management and screenshot update

This update publishes the accepted desktop interaction fixes without exporting
local account settings or a home-directory backup.

- Tiles restore a saved floating size when moved out of tiling; invalid/missing
  sizes use a bounded 60% × 70% viewport fallback.
- Internal edges resize adjacent tile widths or row heights. The grid stores its
  proportions across configuration reloads and respects client size constraints.
- Activating another ordinary app exits the previous fullscreen on its workspace.
  Dialogs, PiP, pinned windows and MateEngine retain their existing exceptions.
  Floating/tiling switches clear fullscreen before laying out windows.
- Neighbouring tiles reflow during close over 700 ms with smooth acceleration and
  deceleration. Other animation timings remain unchanged.
- The screenshot picker captures a cursor-free frame before taking focus, so open
  menus remain visible. It offers Flameshot, active-window capture and local OCR.
  The mouse shortcut still opens Flameshot directly.
- Minimize restoration and maximized geometry use the current window/output state.

The screenshot helpers/icons are selected text sources. Hardcoded author-home
paths were replaced with the installing user's XDG config directory. Existing
account-integration gates, generic first-run settings and license notices remain.
No runtime settings, wallpaper selections, account identifiers, credentials,
personal launchers, device identifiers, logs or screenshots are included.

See [configuration](configuration.md) for controls and dependencies,
[privacy](privacy.md) for publication boundaries and [validation](validation.md)
for the difference between local checks and a clean-machine GUI test. The
compositor pin is unchanged. The follow-up below extends the dependency build recipes.
