# October desktop source update

The publication now carries the selected 2026-10-04 desktop source. Install the
exact compositor revision from `sources.json`; the old September integration
branch lacks the APIs used by the new effects. Existing desktop sessions are not
modified by downloading or inspecting this repository.

## Added and updated

- Home Zone and Gaming Home Zone presets alongside the existing arrangements
  and the empty first preset. Clock mascots, a calendar, local system profile,
  disk/process telemetry and public provider-status indicators.
- Screen shader picker, procedural snow and aquarium effects, generic output
  transitions, live wallpaper helpers and the associated Qt shader sources.
- Panel lifecycle, notification/tray interaction, wallpaper-picker selection
  restoration and transition/snapshot handling from the current desktop.
- MateEngine window policy and IPC: global pointer/window snapshots, workspace
  visibility, movement across outputs/desktops, window/dock ledges and occlusion.
- Music spectrum source detection plus the current MateEngine track title,
  author and optional cover. Missing artwork uses an original neutral SVG;
  neither tracks nor model thumbnails are shipped.

## Local configuration

Choose your wallpaper directory with `SHOJI_WALLPAPERS` and optional primary
output with `SHOJI_PRIMARY_OUTPUT`. The first launch stays on the empty preset
and the neutral SVG. Add dock pins and profile links/tags locally. Account
collectors and the Hermes HUD remain disabled unless explicitly enabled through
the existing `integrations.env` mechanism. Home Zone's account tiles use those
same gates; no author account or login is included.

Generated mascot atlas PNGs are artwork for the clock widget, not screenshots
or MateEngine models. Personal wallpaper collections, application settings,
music catalogs, models, DLC, caches and credentials are excluded.
The exported PNGs retain their original image chunks; generator metadata is
excluded. Steam Wallpaper Engine scenes/videos are not bundled. Live wallpaper
playback additionally requires `linux-wallpaperengine` and the installing user's
own locally available Wallpaper Engine assets; static wallpapers work without it.

## Integration boundaries

MateEngine requires the matching application bridge; installing these dotfiles
alone does not port a stock Windows player. Application source is maintained in
[MateEngine-Linux](https://github.com/howdeploy/MateEngine-Linux). This source
update does not bundle or launch that application.

The compositor retains two local pet policies described in its
[snapshot notes](https://github.com/howdeploy/ShojiWM/blob/2c767129e5a900310b4d53df9f5952a30f6b5953/DESKTOP-SNAPSHOT.md).
The generic client input-region fix is separately submitted as
[upstream PR #122](https://github.com/bea4dev/ShojiWM/pull/122).

The original source was used on the author's desktop. The sanitized publication
has not received a fresh build or graphical acceptance check. Read the
[validation record](validation.md) for the precise boundary.
