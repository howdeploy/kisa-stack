# October 28 desktop source update

This snapshot refreshes selected sources from the working ShojiWM/Quickshell
configuration. Use the exact compositor revision in `sources.json`; the previous
pin lacks the output-power API used by the new lock controller.

- System settings drawer for monitors, input, audio, connections, desktop/lock
  wallpaper and idle timers; display trials revert after 20 seconds without confirmation.
- Wayland/PAM lock screen, per-output face, safe preview and DPMS requests.
- Native lock-scene integration: live wallpaper/MateEngine behind the
  form and a post-authentication unlock wave. The earlier local implementation
  was built, installed and accepted for wallpaper/screensaver behavior; the
  generic public API still needs runtime validation. See
  [required builds and validation limits](lock-scene.md).
- Native animated controls from SL UI, with retained MIT attribution.
- Shared wallpaper crop math and settings thumbnail requests.
- Dock IPC reconnect recovery, MateEngine idle/stacking changes and corrected
  music-spectrum eligibility for paused MateEngine tracks.
- Portal startup-limit reset before restarting session portals and the launcher.
- Generic game placement and Minecraft fullscreen dock spacing, without the
  author's personal game list.
- Source patches for wallpaper-engine D-Bus polling/memory behavior, mpv OpenGL
  fence accumulation, and animated wallpaper crop/upscaling. See
  [separate build instructions](wallpaper-engine.md).
- Published installed-package inventories and separate core/wallpaper/integration
  dependency profiles. Default dock pins no longer require private optional apps.
- A complete private engine/CEF/mpv builder, backed-up bundle installation and
  direct executable launch, bypassing system wrappers that override library order.
- The latest asynchronous media fix from PR #711 and a minimal public MateEngine
  lock-state bridge patch, with exact source revisions and build instructions.

`system-settings.json` is private local state. It is ignored, excluded from source
copies and preserved with `wallpapers.json` and `integrations.env` on upgrades.
The empty preset, neutral background, opt-in account gates, configurable paths
and portable shell startup remain. No private music catalog, wallpapers, account
state, binaries, personal app pins or workstation-specific startup actions were copied.

No installer, tests, build, lint, typecheck or graphical checks were run for this
source refresh. Lock authentication/unlock and DPMS behavior in the public copy
still need a deliberate user check. No live session was reloaded or changed.
