# VPN / cyber / privacy tech prompt bank

Use this when the user needs instrumental background music for videos about VPNs, privacy, routing, bypass systems, censorship resistance, or "built with AI" tech explainers.

## Core framing
The sweet spot is usually not generic corporate tech music. Better results come from a mix of:
- dark cyber atmosphere
- restrained glitch texture
- minimal or moderate pulse
- no vocals
- background-safe arrangement

Think: privacy, tunnels, packet flow, hidden routing, encrypted traffic, neon network mood.

## Two reliable prompt families

### 1. Dark glitch cinematic
Best when the video wants stealth, seriousness, hidden infrastructure, bypassing restrictions.

```text
Dark glitch hacker atmosphere, cinematic tech thriller, deep pulsing bass, sparse electronic percussion, subtle digital noise, network signal textures, encrypted data feel, cold neon mood, stealthy and intelligent, minimal but tense, futuristic underground internet vibe, no vocals, instrumental only, smooth build, background music for a video about VPN, privacy, bypassing restrictions, and AI-made tech solutions
```

Expected feel:
- darker
- more cinematic
- stealth / tunnel / underground network vibe

### 2. Rhythmic cyber pulse
Best when the video is more like: "look how I built this" and needs modern motion.

```text
Minimal dark cyber electronic, glitchy rhythmic pulse, sleek tech beat, tight bassline, crisp percussion, digital textures, synthetic arpeggios, modern hacker aesthetic, fast network traffic feel, clean but edgy, futuristic and stylish, no vocals, instrumental only, no aggressive drops, background track for a video about building a VPN with AI, privacy tech, routing, and bypass systems
```

Expected feel:
- cleaner
- more energetic
- more modern/product-engineering vibe

## Refinement directions

If the first result is too dramatic:
- add `background underscore`
- add `voiceover-safe`
- add `no lead melody`
- add `designed to stay under narration`

If the first result is too bland:
- add `cold neon mood`
- add `network signal textures`
- add `glitchy rhythmic pulse`
- add `modern hacker aesthetic`

If the first result is too aggressive:
- add `restrained arrangement`
- add `smooth build`
- add `no aggressive drops`
- add `minimal but tense`

## Practical lesson
For VPN/privacy videos, user intent often splits into two different background needs:
1. **stealth / hacker / encrypted tunnel** mood
2. **sleek builder / modern tech explainer** mood

Generate at least one version for each family instead of trying to force both into one prompt.
