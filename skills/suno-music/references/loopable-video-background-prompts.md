# Loopable video background prompts

Use these when the user needs background music that can be stretched under video by looping the file.

## Core loop formula
Always bias prompts toward **bed / underscore / loop** rather than "song".

Core phrases that help:
- `instrumental only`
- `seamless loop` / `seamless looping`
- `loopable background bed`
- `perfectly loopable 8-bar or 16-bar cycle`
- `no hard intro`
- `no hard outro`
- `no fade-out`
- `matching start and end energy`
- `stable harmony`
- `smooth loop transition`
- `designed to sit under voiceover`

## Prompt family 1 — muted chill synthwave
```text
Instrumental only. Muted chill synthwave underscore for spoken-word video. Warm analog pads, multiple soft synth layers, subtle low pulse, light vintage drum machine, smooth bass, calm neon-night atmosphere. Unobtrusive, low emotional intensity, no vocals, no strong melody, no dramatic intro, no dramatic outro, no risers, no drop, no big fills. Compose as a seamless looping 16-bar bed with constant energy and smooth loop transition, designed to be extended under video narration.
```

## Prompt family 2 — cold soviet-wave
```text
Instrumental only. Seamless loopable soviet-wave background bed for video. Cold nostalgic synth atmosphere, layered analog pads, soft chorus synths, restrained drum machine, muted bass pulse, distant melancholic arpeggio, dreamy and reflective, minimal and unobtrusive. No vocals, no catchy lead, no ending resolution, no fade-out, no bright EDM elements. Built as a seamless 16-bar loop with stable mood and beginning/end designed to connect cleanly for infinite extension under narration.
```

## Prompt family 3 — soft retro ambient synth
```text
Instrumental only. Soft retro ambient synthwave loop for video background. Dense but gentle synth textures, lush pads, subtle analog motion, mellow bass, understated sequencer pulse, slightly dreamy documentary feel. No vocals, no lead hook, no cinematic build, no snare fills, no hard intro or outro. Written as a perfectly loopable 16-bar cycle with matching start and end energy, smooth loop point, and unobtrusive mix for voiceover.
```

## Compression rule
For EvoLink/Suno non-custom mode, keep prompts compact. If the API starts rejecting a descriptive prompt, shorten adjectives and remove duplicated negatives before changing the musical idea.
