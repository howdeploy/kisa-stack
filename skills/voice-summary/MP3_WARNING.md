# ⚠️ КРИТИЧЕСКОЕ ПРАВИЛО: MP3 голосовые СЛОМАНЫ

## Проблема

TTS иногда генерирует `.mp3` файлы вместо `.opus`.

**MP3 в Telegram:**
- ❌ Приходит как **обычный файл**, НЕ как голосовое сообщение
- ❌ Бесполезен для голосовой коммуникации
- ❌ Выглядит как баг

**OPUS в Telegram:**
- ✅ Корректно отображается как голосовое
- ✅ Работает как надо

## ПРАВИЛО (железобетонное!)

**ЕСЛИ получила .mp3 файл → НЕ ОТПРАВЛЯТЬ!**

Применяется:
- ✅ В личке с пользователем
- ✅ В канале
- ✅ Везде где используются голосовые

## Как проверить

(Пример ниже — для Hermes-подобного агента: `tts()` и `message()` — его API. Суть правила универсальна для любого рантайма.)

```javascript
// После tts() получаем путь
const voicePath = tts_result.path; // например /tmp/tts-xxx/voice-123.mp3

// Проверяем расширение
if (voicePath.endsWith('.mp3')) {
  // НЕ ОТПРАВЛЯТЬ!
  // Лучше вообще пропустить голосовое
  return;
}

if (voicePath.endsWith('.opus')) {
  // OK, можно отправлять
  message(filePath=voicePath, asVoice=true);
}
```

## Что делать вместо отправки MP3

**Варианты:**
1. Пропустить голосовое совсем (лучше ничего, чем файл)
2. Попробовать регенерировать через tts() ещё раз (может даст opus)
3. Сказать пользователю текстом что хотела голосовое, но сгенерировалось MP3

**НЕ делать:**
- ❌ Отправлять MP3 как голосовое (не работает)
- ❌ Отправлять MP3 как файл (бесполезно)

## Почему так происходит

ElevenLabs API иногда возвращает MP3 вместо OPUS. Это их баг, мы не можем контролировать.
