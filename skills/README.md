# Archived task-specific skills

These directories preserve earlier skill publications. They are not KISA's current personal workflow or a recommended installation bundle. See the [current five-component workflow](../README.md#current-workflow).

Review a skill's instructions, dependencies and runtime assumptions before choosing to use it. Install only a specifically selected skill:

```bash
./install.sh <skill-name> --claude
./install.sh <skill-name> --codex
./install.sh <skill-name> --hermes
```

Run the installer from the repository root. Bulk installation is disabled. The current workflow integrations are installed separately from their upstream projects.
