# Extraction Buckets for Telegram Chat Wiki

Use this cheat sheet after the raw dialogue chunks already exist.

## What to extract

### Projects
- names of projects
- repeated workstreams
- launches, launches blocked, deadlines, current state

### Prompts
- direct prompt text
- instruction patterns
- reusable agent/task formulations

### Practices
- workflows
- habits
- operational routines
- tools and service choices

### Advice
- recommendations
- critiques
- arguments
- lessons learned

### Contacts
- usernames
- roles
- who knows whom
- companies / channels / groups

### Facts
- durable preferences
- constraints
- plans
- statuses that are likely to matter later

## Filter rule
Do not extract every message. Extract only what is durable, reusable, or repeatedly relevant.

## Suggested question prompts
- What were the main recurring topics in this chat?
- Which projects came up more than once?
- What practical advice did this person give?
- Which facts are stable enough to preserve?
- Should any of this become an entity/concept/query page?
