# Suggested allowlist for gamer-signal

## Tier A — preferred
- store.steampowered.com
- steamcommunity.com
- official game / studio / publisher domains

## Tier B — allowed community knowledge bases
- pcgamingwiki.com
- *.wiki.gg
- gamefaqs.gamespot.com
- strategywiki.org

## Tier C — fallback only, explicitly marked as lower confidence
- *.fandom.com
- *.wikia.com

## Default exclusions
- Reddit
- YouTube
- random blogs
- SEO guide farms
- AI-generated content mills
- forum mirrors outside the allowlist

## Query pattern hints
- site:steamcommunity.com/app
- site:store.steampowered.com
- site:pcgamingwiki.com
- site:wiki.gg
- site:gamefaqs.gamespot.com
- site:strategywiki.org
