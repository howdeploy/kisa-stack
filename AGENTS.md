# tab-stack

This repository is `tab11pm/tab-stack`, the user's desktop and AI tooling stack.
The local checkout is separate from the installed desktop configuration. The
upstream project is `howdeploy/kisa-stack`; retain its provenance, copyright and
licenses, but use `tab-stack` for current project branding, descriptions,
documentation, clone commands and source references.

Read `dotfiles/AGENTS.md` before changing desktop publication source. Installed
configuration under `~/.config` is a separate target; do not overwrite either
copy with the other without a request to install or synchronise changes. Do not
publish credentials, integration settings, wallpapers, runtime state or backups.
